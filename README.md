- Connexion individuelle par mot de passe
- Tableau de bord
- Dossiers patients
- Modification / suppression des patients
- Rendez-vous avec modification / suppression
- Statuts des rendez-vous
- Calendrier mensuel
- Salle d'attente
- Consultations complètes avec constantes
- Historique par patient
- Ordonnances fictives imprimables
- Examens / analyses fictifs
- Documents fictifs
- Statistiques
- Administration
- Données locales uniquement
- Aucun Firebase

## Installation GitHub

Remplace les anciens fichiers par :
- `index.html`
- `style.css`
- `app.js`
- `README.md`

Puis fais **Commit changes**.

Pour GitHub Pages :
Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.

⚠️ Simulation de jeu uniquement. Ne saisissez aucune donnée médicale réelle.
