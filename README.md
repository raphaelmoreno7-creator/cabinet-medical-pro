# Cabinet Médical Pro V2 — Simulation

Version de jeu fictive pour Raphaël, Jade et Victoria.

## Nouveautés V2
- Suppression des rendez-vous
- Modification des rendez-vous
- Statuts : prévu, arrivé, en attente, en consultation, terminé, annulé
- Salle d'attente
- Suppression des consultations
- Modification des consultations
- Dossiers patients modifiables et supprimables
- Historique de consultations par patient
- Constantes fictives
- Examen clinique, diagnostic et traitement fictifs
- Vaccinations fictives
- Données locales uniquement

## Installation
Remplacer les anciens fichiers du dépôt GitHub par `index.html`, `style.css`, `app.js` et `README.md`.

## GitHub Pages
Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.

⚠️ Ce logiciel est une simulation de jeu. Ne saisissez aucune donnée médicale réelle.
