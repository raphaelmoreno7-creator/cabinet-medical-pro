# Cabinet Médical Pro V4 — Simulation

Version de jeu fictive pour Raphaël, Jade et Victoria.

## Connexion
- Raphaël : `2012`
- Jade : `2017`
- Victoria : `2017`

## Nouveautés V4
- Bouton **Afficher** dans les consultations : lecture seule, sans modification.
- Bouton **Télécharger** : télécharge une fiche HTML complète de la consultation.
- Bilan alimentaire directement dans chaque consultation.
- Saisie par repas : petit-déjeuner, déjeuner, goûter, dîner, grignotage.
- Base de nombreux aliments et plats avec catégories alimentaires.
- Quantité en portions pour chaque aliment.
- Pyramide alimentaire personnalisée dans l'affichage de la consultation.
- Pyramide incluse dans le document téléchargé.
- Conservation locale dans le navigateur.

## Installation GitHub
Remplace les 4 fichiers : `index.html`, `style.css`, `app.js`, `README.md`, puis fais **Commit changes**.

⚠️ Simulation de jeu uniquement. Ne saisissez aucune donnée médicale réelle. Les aliments, calculs et pyramides sont des visualisations pédagogiques fictives et ne constituent pas un conseil médical.
