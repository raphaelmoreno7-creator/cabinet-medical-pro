# Cabinet Médical Pro — Simulation

Logiciel médical fictif pour jouer au docteur avec Raphaël, Jade et Victoria.

⚠️ Ce projet est uniquement un jeu : toutes les données sont fictives.

## Mise en ligne avec GitHub

1. Crée un dépôt GitHub, par exemple `cabinet-medical-pro`.
2. Ajoute les quatre fichiers : `index.html`, `style.css`, `app.js`, `README.md`.
3. Va dans **Settings → Pages**.
4. Sous **Build and deployment**, sélectionne **Deploy from a branch**.
5. Choisis `main` puis `/ (root)`.
6. Clique sur **Save**.
7. Après quelques instants, GitHub Pages affichera l'adresse de ton logiciel.

## Utilisation

À l'ouverture, choisis Raphaël, Jade ou Victoria.
Les patients, rendez-vous et consultations sont enregistrés dans le `localStorage` du navigateur : aucun Firebase et aucune synchronisation entre appareils.

## Fonctionnalités

- Profils Raphaël / Jade / Victoria
- Tableau de bord
- Dossiers patients
- Rendez-vous
- Consultations
- Recherche de patients
- Données locales
- Interface Mac / iPad
